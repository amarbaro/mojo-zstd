# mojo-zstd v0.1.0

**Released:** 2026-11-04 · **Commit:** `83246af` · **Previous:** first release

## What it does

zstd and lz4 frame compression for Mojo through the system `libzstd` and `liblz4`: one-shot
`compress`/`decompress`, and streaming zstd files or buffers through a 128 KiB window.

## Highlights

- Parity with Python on the same C libraries: zstd level 3 on 32 MiB text, compress 61 to 63 ms (Python 61 to 66), decompress 34 to 36 ms (Python 38 to 42).
- Streaming 128 MiB through `ZstdWriter`/`ZstdReader` peaks at 13.7 MB RSS, the same as 1 MiB.
- Corrupt, truncated or trailing input raises `zstd: ...` / `lz4: ...`, never a crash.

## Known limits

- Parity, not a faster codec: the same C libraries do the work. One zstd compress run read 179 ms, a noisy outlier.
- Linux; needs `libzstd.so.1` and `liblz4.so.1`. No dictionaries, no threads, no lz4 block format.

## Upgrade / run

`mojo run -I src app.mojo`
